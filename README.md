# LAB36

> Nơi ý tưởng được thử thách, không chỉ được dạy.  
> Where ideas are tested, not just taught.

**LAB36** là một tập thể công nghệ thử nghiệm, xây dựng các công cụ thông minh với sự rõ ràng và chính xác. Chúng tôi tập trung vào việc phát triển các dự án web hiện đại, từ game mô phỏng đến nền tảng AI workspace.

## 🚀 Dự án nổi bật

### Season 1
- **Black MMO** - Game mô phỏng jackpot và gamble giải trí với hiệu ứng casino hiện đại
- **Titan Futures** - Mô phỏng giao dịch futures chuyên nghiệp với chart realtime
- **MMO SIMULATOR** - Trải nghiệm MMO theo dạng challenge với hệ thống nhiệm vụ

### Season 2
- **VibraX** - Nền tảng âm nhạc hiện đại trên web với trải nghiệm nghe nhạc mượt mà
- **StudyTok** - AI workspace giúp biến ghi chú thành summary, flashcards và quiz
- **Facebook Note Breaker** - Tiện ích Chrome giúp viết ghi chú Facebook dài

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS + Custom CSS
- **Animation**: Framer Motion
- **Deployment**: Vercel

## 🎨 Design System

- **Color Scheme**: Midnight Indigo + Cyan
- **Background**: #070B14 / #0F172A
- **Accent**: #38BDF8 (Cyan)
- **Typography**: Inter font family
- **Style**: Glassmorphism with subtle glow effects

## 🌐 Features

- ✅ Bilingual support (Vietnamese/English)
- ✅ Responsive design (PC, Mobile, Tablet)
- ✅ Smooth animations with Framer Motion
- ✅ Modern glassmorphism UI
- ✅ SEO optimized
- ✅ Fast performance with Next.js Turbopack

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the site.
